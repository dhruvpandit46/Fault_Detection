Fault Detection is a responsive web dashboard for monitoring electrical transmission lines in real time.

The application visualizes transmission line faults, affected phases, current measurements, fault locations, and system health using Firebase Realtime Database as the live data source.

Designed with a mobile-first interface, it provides operators with a clear overview of the electrical network through interactive visualizations and real-time updates.

# ⚙ How It Works

1. Electrical sensors collect phase current data.

↓

2. The controller processes the measurements.

↓

3. Fault information is uploaded to Firebase.

↓

4. The dashboard receives live updates instantly.

↓

5. Users can monitor:

- Current values
- Fault type
- Fault distance
- Affected phases
- System status

# 📦 Installation

Clone the repository

```bash
git clone https://github.com/dhruvpandit46/Fault_Detection.git
```

Go inside the project

```bash
cd Fault_Detection
```

Open

```
index.html
```

in your browser.

Configure your Firebase project by updating the Firebase configuration inside the application before deployment.
